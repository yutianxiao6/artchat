# App icons

- `app-icon.svg`：主图标源文件，适合后续导出 PNG / ICO
- `favicon.svg`：网站 favicon

## 建议用途

- 网站标签页图标：`frontend/assets/favicon.svg`
- Windows 程序图标：先把 `app-icon.svg` 导出为 `app-icon.ico`

## 推荐导出规格

### favicon
- 32x32
- 64x64

### Windows ICO
一个 `.ico` 里建议包含：
- 16x16
- 24x24
- 32x32
- 48x48
- 64x64
- 128x128
- 256x256
